# Imeijiz | ایمیجیز

![Imeijiz](branding/imeijiz-logo-dark.svg)

Imeijiz is a Windows app for upscaling images and removing backgrounds. It is based on [Upscayl](https://github.com/upscayl/upscayl).

ایمیجیز برنامه‌ای برای افزایش وضوح تصاویر و حذف پس‌زمینه در ویندوز است.

## Windows downloads

The installer and portable package will appear under [Releases](https://github.com/mmahdighafoori10/imeijiz/releases) once they pass testing.
